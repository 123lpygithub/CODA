# CodeErrors — 逐条阅读归纳的 codebook（deepseek-1）

557 个 artifact · 定义 15 个主题代码（其中 14 个在本批有成员） · 735 条 artifact–code 成员关系 · 171 条多标签 artifact。

本版来自逐条完整阅读、开放编码、持续比较与显式归并。每条 artifact 至少有一个代码；允许在材料支持多个独立机制时多标签。脚本只序列化人工判断并校验数量、成员与逐字证据，不依据关键词、正则、发布标签或旧分类自动决定类别；旧底稿只用于对照复核，所有边界判断均回到冻结原文。

本版是一个 AI 编码者的材料归纳，不是独立人工双编码，也不把“结构校验通过”表述为解释唯一或法律/安全事实已被验证。

## 使用规则

- 分析单位是去重后的一个错误解法；同一任务的不同模型/不同错误源码分别保留。
- 代码描述可从源码直接观察到的失败机制，不根据模型名、任务编号或数据集旧标签决定类别。
- 目标被替换（CE05）与同一目标下的覆盖不足（CE06）、公式错误（CE09）分开；确实同时存在时多标签。
- 语法截断（CE02）与未交付实现（CE01）可并存；未定义名称（CE03）与类型协议错误（CE12）也可并存。
- 证据统一取冻结内容中 “Incorrect Code (Generated by LLM)” 到 “Correct Code (Ground Truth)” 之间的完整错误源码。

## CE01 实质实现未交付

目标函数没有形成可执行的主体实现：pass、仅注释、固定常量或只覆盖示例。

- 纳入：空函数体、只有注释、无有效返回、用与输入无关的常量或示例值顶替求解。
- 排除与边界：主体逻辑存在但覆盖不全用 CE06；调用未定义名称用 CE03；源码截断用 CE02。；只有局部语句缺失但算法主体可运行，不归 CE01。
- 支持：81 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE02 源码截断或语法不完整

冻结源码在 token、表达式、容器或缩进块中途结束，模块无法解析。

- 纳入：括号/引号未闭合、缩进块中断、表达式截断、语法错误导致不可导入。
- 排除与边界：合法语法但缺 return 用 CE01；运行时类型错误用 CE12。；截断同时导致无实现时并用 CE01 与 CE02。
- 支持：31 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE03 未定义或未提供的名称

正常路径引用本 artifact 未定义、未导入、任务也未承诺提供的模块、函数或变量。

- 纳入：调用未定义 helper、未导入模块、拼错名称、使用未绑定变量。
- 排除与边界：对象存在但操作不支持用 CE12；名称在另一段被定义则不算。；任务描述承诺由测试环境提供的名称不归 CE03。
- 支持：35 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE04 解析、分词或表示转换错误

输入被按错误边界或错误表示域解释，或文本/字符/数值/结构表示转换不成立。

- 纳入：错误分隔符、错误字段边界、把英文数字直接 int、错误类型转换、分词丢元素。
- 排除与边界：解析正确但公式错用 CE09；输出格式不符用 CE13。；字符级大小写/字符集规范问题优先 CE14。
- 支持：19 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE05 计算目标被替换

实现计算了可辨识但与契约不同的量、对象、谓词或粒度。

- 纳入：求极值代替最近对、按字典序代替数值序、判断偶数代替判素、返回常量目标。
- 排除与边界：目标正确但候选/循环覆盖不全用 CE06；目标正确但公式写错用 CE09。；错误目标本身仍可运行，不能仅因结果错就归 CE05。
- 支持：268 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE06 遍历、候选或状态覆盖不足

目标量正确，但循环边界、候选枚举、状态推进或累积覆盖不完整。

- 纳入：少遍历元素、提前停止枚举、漏状态分支、边界少一轮、只检查部分候选。
- 排除与边界：完全换掉目标用 CE05；条件写反用 CE07。；筛选条件本身错误归 CE05/CE07；漏掉应检查的成员归 CE06。
- 支持：55 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE07 条件判断或提前返回错误

分支条件、终止条件或提前返回使错误路径被选择。

- 纳入：比较方向反、and/or 混用、return 位置错误、基线条件错误、循环终止条件错。
- 排除与边界：边界输入未校验用 CE11；数学递推公式错用 CE09。；条件正确但漏候选归 CE06。
- 支持：26 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE08 结果组装、顺序或重数错误

元素、位置、顺序、重复次数或返回结构被错误组装。

- 纳入：分隔符位置错、奇偶重排、丢首尾元素、重复添加、嵌套层级/顺序错。
- 排除与边界：输出类型/格式契约错用 CE13；计算值本身错用 CE05/CE09。；结果元素正确但顺序错，归 CE08。
- 支持：40 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE09 数学公式、递推或数值方法错误

目标量正确但公式、递推关系、取整或数值方法本身写错。

- 纳入：递推式错、取模/回绕缺失、平均/中位数公式错、二分/筛法方法错、浮点处理错。
- 排除与边界：目标量被替换用 CE05；初始化/状态转移错用 CE10。；数学方法正确但循环少一轮归 CE06。
- 支持：85 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE10 初始化或状态转移错误

初始值、变量更新或状态转移步骤写错，导致后续计算基于错误状态。

- 纳入：累加器初值错、余额未更新、DP 转移错、循环变量更新错。
- 排除与边界：循环边界少一轮用 CE06；条件方向错用 CE07。；状态变量存在但从未更新，归 CE10 而非 CE01。
- 支持：9 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE11 输入域、类型或边界校验缺失

未处理契约要求处理的边界值、非法输入或类型差异。

- 纳入：空输入、负数、零、单元素、非法日期、越界下标、未捕获转换异常。
- 排除与边界：类型不支持所调用操作用 CE12；正常输入上的逻辑错不归 CE11。；边界处理存在但判据写错，按具体机制归 CE07/CE09。
- 支持：34 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE12 对象类型或操作协议不相容

对现有对象施加了其类型不支持的运算或调用，产生运行时错误。

- 纳入：字符串索引列表、字符取模、对 None 调用方法、参数结构不符合 API。
- 排除与边界：名称未定义用 CE03；合法操作但公式错用 CE09。；同一表达式既有未定义名又有类型错时并用 CE03/CE12。
- 支持：20 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE13 输出格式或表示契约错误

返回值的类型、格式、前缀、大小写或字符串表示不符合任务契约。

- 纳入：返回 lambda/元组/列表类型错、缺前缀、连接符错、大小写表示错。
- 排除与边界：元素内容本身算错用 CE08；字符级比较规范错用 CE14。；格式与内容同时错时并用 CE08/CE13。
- 支持：15 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE14 字符或大小写规范语义错误

字符级比较、大小写或字符集规范被错误应用。

- 纳入：大小写不敏感比较、大小写转换范围错、字符集/编码判断错、元音/字母分类错。
- 排除与边界：整串解析错误用 CE04；输出格式错用 CE13。；字符级规则正确但遍历范围错，可并用 CE06。
- 支持：17 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## CE15 按提供材料未观察到可归因缺陷

逐条核对任务契约、错误源码与正确源码后，未发现可由现有代码描述的独立失败机制。

- 纳入：实现与契约一致，或差异仅是未被材料支持的推测。
- 排除与边界：存在不确定或未覆盖输入时，应保留具体边界代码，不应使用 CE15。；CE15 不是“完全无错”的证明，只表示按本条提供材料未观察到可归因缺陷。
- 支持：0 个 artifact。完整成员见 `codebook.json` 的 `artifact_ids`。

## 文件说明

- `codebook.json`：代码定义、边界与全部成员 ID。
- `assignments.jsonl`：逐条代码、开放代码、备忘录、逐字证据、内容哈希与分析依据。
- `artifacts.jsonl`：冻结语料原文。
- `memberships.csv`：artifact–code 长表。
- `artifact_index.csv`、`reading_memos.csv`：便于浏览与复核的索引。
- `coverage_report.json`：数量、缺失、重复、未定义代码、证据与双向成员校验。
- `METHOD.md`：实际执行过程、材料边界与限度。
